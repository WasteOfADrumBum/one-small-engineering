## How to read this

- **Readiness** is verified gates divided by applicable gates, rounded down. Builder-reported results, CI runs and pass records made before an independent verifier was assigned count as zero.
- **Blockers** counts open blockers recorded in the registry (manual, governed records that automation never adds or removes) plus blockers the engine derived from the registry (proposals that are never written back). The registry-recorded count is in brackets.
- **Last evidence** is the newest evidence record in the registry for the project. Repository snapshots are refreshed by registry sync; see each project report for the snapshot date.
- **Next recommended action** is the highest-priority item derived from evidence: security, broken functionality, missing verification, CI, accessibility, release artifacts, then documentation.
