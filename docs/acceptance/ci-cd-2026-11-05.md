## 6. Independent review

1. **Independent review agent** (a separate Claude agent with no part in writing the change; read-only; it ran the tests and gitleaks itself). It reported 8 findings, all fixed in `7e0d10b`/`6ca2347`:
   - (high) every sandboxed git checkout failed with "dubious ownership", which would have made every sandboxed collection `unavailable` (reproduced, fixed with `-c safe.directory=*` as an argument, covered by the self-test);
   - (medium) the gitleaks allowlist ORed its criteria and hid any secret in evidence files (fixed with `condition = "AND"` plus a self-check that fails without it, verified both ways);
   - (medium) sandboxed commands inherited the hub's cwd and the hub wrote world-writable files (cwd confined to the work root, umask 0000 removed);
   - auto-merge wait budget and cancelled attempts; policy false negatives (`write-all`, `secrets[...]`, setup order); `validate-registry.mjs` not triggering isolation; cron/at survival; the gate being advisory for non-sync PRs (documented).
   It confirmed as correct: pagination with `filter=all`, the field names the trusted-source binding reads, newest-attempt selection, zero-job runs neither blocking nor satisfying, gate semantics for `always()`/skipped/cancelled, and `merge_group` fields.
